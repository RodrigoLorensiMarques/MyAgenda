# MyAgenda

## Requisitos 
- Python 3>
- Docker

## Como executar
### Subindo o MongoDB
No diretório raiz da aplicação execute `docker-compose up` para subir o container do MongoDB

### Instalar dependências 
Execute um `pip install -r requirements.txt` para instalar as dependências da aplicação


### Rodando aplicação
No terminal, execute o `main.py` e pronto, a aplicação estara rodando!
